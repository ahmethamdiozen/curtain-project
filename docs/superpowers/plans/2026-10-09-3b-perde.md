# 3B Perde Implementation Plan

> Executed natively (user: "tüm fazları tamamla ve yayınla"). Spec: `docs/superpowers/specs/2026-10-09-3b-perde-gercekcilik-design.md`

**Goal:** Replace the 2D curtain shader with real 3D curtain meshes rendered in the photo's recovered camera, lit and shadowed, then matched to the photo (white balance, exposure, black level, grain).

## Global Constraints
- World units cm; wall z=0, room z<0, y down; corners TL,TR,BR,BL.
- `packages/engine` stays React/DOM-free; three.js gets `{canvas, context}` from the caller.
- Recolor = uniform update only (no geometry rebuild, no server call).
- Static Pages demo must keep working (regenerate assets/demo after server changes).

## Review Focus
1. Near-frontal photo (no perspective) → pose still valid (test: pose.test frontal).
2. Floor not visible / hidden by sofa → curtain falls to default length, no crash (test: floor.test occluded + none).
3. Degenerate corners → last valid pose kept, photo still shown (existing e2e degenerate.mjs).
4. Very dark / very bright scenes → exposure stays bounded (test: light stats clamps; composite clamp).
5. Old scene JSON without `light` → defaults used (test: defaults in engine `lightOrDefault`).

## Tasks
1. Server `light` stats in analyze + tests; regenerate demo JSON.
2. Engine `pose.ts` + tests.
3. Engine `drape.ts` (all families + hardware) + tests.
4. Engine `floor.ts` + `matching.ts` (light defaults, exposure, WB) + tests.
5. Engine `renderer3d.ts` (three.js scene, LAB material injection, lights, shadow catchers, composite) replacing `renderer.ts`; web app wiring (mask ImageData → floor, light → renderer).
6. Visual tuning on 5 samples; e2e regression (typing, degenerate, static); deploy.
